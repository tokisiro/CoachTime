# CoachTime

## 概要
    このアプリケーションは勤怠管理を行うためのWebアプリケーションです。

## 環境構築

### リポジトリの設定

    ①アプリを作成したいディレクトリに移動

    ②リポジトリをクローン
        git clone git@github.com:tokisiro/CoachTime.git

    ③リポジトリ名を変更

    ④リポジトリのURLの変更(開発する場合)

        1 ③で変更したリポジトリに移動
        2 git remote set-url origin 作成したリポジトリのurl
